overview

A puzzle game built in 72 hours for GMTK Game Jam 2025 (theme: "Loop"). Built by Rat Haven Studios!

Program a sequence of movement commands that execute on repeat. Ranked in the top 6% of 9,500+ submissions.

View the rankings on the Jam Page.

gameplay

Rotation commands make multi-step sequences genuinely tricky: the same command does different things depending on which way you're facing.

If you get stuck, there's a hints and solutions cheat sheet on the itch.io page.
