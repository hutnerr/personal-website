beast[code]

$ a Discord bot that posts LeetCode problems and server notifications

overview maintained

beast[code] is a Discord bot meant to add some friendly competition and accountability to LeetCode practice for CS students.

It's mean features are the ability to define reoccuring problems on a schedule and a leaderboard to make progress visible and competitive. It also posts alerts for upcoming contests and the official daily challenge, giving server members a shared target to aim for each day.

tech stack

  • Python (Discord.py, Aiohttp)
  • GraphQL (LeetCode API)
  • JSON file persistence with in-memory cache

features

  • Scheduled problem delivery - Admins configure up to 5 recurring problems by day, time, and difficulty; the bot posts them automatically so there's always something to solve
  • Point-based competition - Solutions are scored by difficulty (Easy · Medium · Hard) and tracked on a live server leaderboard, making progress visible and competitive
  • Account linking - Users link their LeetCode username once; then submit with /submit to gain points
  • Contest alerts - Get notified when upcoming LeetCode contests are about to go live, so no one misses a timed event
  • Daily problem - Posts the official LeetCode daily challenge on demand, giving the server a shared daily target
  • Per-server configuration - Every server gets its own schedule, leaderboard, and settings.
