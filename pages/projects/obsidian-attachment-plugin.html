overview

Obsidian gives you one global folder for all attachments. This is fine for small vaults, but becomes painful once your vault grows into multiple structured sections. This plugin lets you define placement rules per folder so pasted and dropped files land where they belong, automatically.

Built out of personal frustration, published to the Obsidian community plugin list, and aimed at anyone who keeps a large structured vault.

features

Per-folder rules

Define rules per folder that automatically route pasted or dropped attachments to the right destination.

Nearest-ancestor matching

Rules closer to the active note take priority, so you can set broad defaults and override them in specific subfolders.

Global fallback

Configurable global fallback for notes that don't match any rule.

Rule reordering

Drag-and-drop rule reordering in the settings panel.

Community install

Installable directly from Obsidian's community plugin list.
