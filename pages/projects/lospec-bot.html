lospec daily bot

$ daily pixel art palette posts from Lospec to your Discord server

overview maintained

This bot was built for Rat Haven Studios to improve pixel art skills.

It posts the Lospec Daily to a set discord channel every morning at 8 AM EST, giving artists a regular prompt and palette to practice with.

Not affiliated with Lospec.

tech stack

  • Python
  • Discord.py
  • Aiohttp (async HTTP)
  • BeautifulSoup4 (HTML scraping)

links

  • GitHub
  • Add to Server
  • Top.gg

features

  • Automatically posts Lospec's daily pixel art palette and prompt to your server every morning at 8 AM EST
  • Set it up once with a single slash command. No ongoing maintenance needed
  • Enable or disable automatic posting at any time without losing your channel configuration
  • Check the current daily palette on demand with /getdailydata, outside of the scheduled post
  • Per-server configuration. Each server controls its own channel and settings independently
