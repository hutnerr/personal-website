gesturtle

a desktop app for timed drawing practice using your own reference library

maintained Java JavaFX SQLite Maven
Download View on GitHub
— github stars

overview

Sites like Line of Action and Quickposes are great for gesture drawing, but you're stuck practicing from their images. I wanted to practice from the references I'd actually collected, so I built a tool around that.

Gesturtle imports your images into a local library, lets you tag and filter them however you like, and turns any slice of that library into a timed practice session in one click. Tagging your own references takes a bit more setup than a pre-built site, but it's far more flexible.

Everything lives in one self-contained folder, so your library is easy to back up, sync, or even keep in git across machines.

features

Flexible sessions

Chain segments together (e.g. 5 × 30s, then 3 × 2min, then 1 × 10min), each drawing from its own tag filter, playlist, or saved view.

Hierarchical tags

Nest tags like animal / bird and filter with And, Or, and Exclude.

Memory drawing

Study an image, draw it from memory, then compare.

Study aids

Flip, rotate, grayscale, blur, grid overlays, and 2 to 4 tone value studies, all without touching the original.

One-click presets

Jump straight into practice from the home page.

Session review

Look back over every image after a session and favorite or tag the keepers.

Easy importing

Drag and drop files, folders, or images straight from a browser, with duplicates caught automatically.

Gruvbox themes

Light and dark modes, plus rebindable keyboard shortcuts.
